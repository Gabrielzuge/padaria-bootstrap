# Padaria Pão Quentinho

Trabalho de HTML com Bootstrap 5. Site simples de uma padaria fictícia, desenvolvido para praticar as classes do framework.

## Tecnologias
- HTML5
- Bootstrap 5.3.3 (CDN)

## Recursos usados
- Tipografia: `text-center`, `lead`, `fw-bold`
- Cores: `bg-warning`, `text-success`, `bg-light`
- Imagens: `w-100`, `card-img-top`
- Alerta: `alert alert-success`
- Botões: `btn btn-warning`, `btn btn-success`
- Cards: `card`, `card-body`, `card-title`
- Navbar: `navbar`, `navbar-expand-lg`
- Carrossel: `carousel`, `carousel-item`
- Flex: `d-flex`, `justify-content-between`, `align-items-center`
- Formulário: `form-control`, `form-label`

## Como abrir
Abra o arquivo `index.html` no navegador. É necessário acesso à internet para carregar o Bootstrap e as imagens.

## Observação
O formulário é somente para demonstrar o uso de classes do Bootstrap. Não envia mensagens para um servidor.
